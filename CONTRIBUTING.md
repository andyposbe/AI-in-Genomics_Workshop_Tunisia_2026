# Adding your slides and worksheets

For trainers and facilitators. No git, no terminal, no coding. You need a free GitHub account and about five minutes.

Repository: https://github.com/andyposbe/AI-in-Genomics_Workshop_Tunisia_2026
Website: https://andyposbe.github.io/AI-in-Genomics_Workshop_Tunisia_2026/

---

## Where does my file go?

| What you have | Folder | Example file name |
|---|---|---|
| A talk or session introduction from **Day 1** | `slides/day1/` | `AF-theory_Posbeyikian.pdf` |
| A talk or session introduction from **Day 2** | `slides/day2/` | `Design-intro_Sugihara.pdf` |
| A **worksheet or handout** for Practical 1 | `worksheets/practical-01_predict/` | `P1-worksheet.pdf` |
| Practical 2 worksheet | `worksheets/practical-02_interpret/` | `P2-worksheet.pdf` |
| Practical 3 worksheet | `worksheets/practical-03_compare/` | `P3-worksheet.pdf` |
| Practical 4 worksheet | `worksheets/practical-04_design/` | `P4-worksheet.pdf` |
| Sequences or other files people need to run a session | `data/practical-0X_.../` | `my-sequences.fasta` |

If your file does not fit any of these, put it in the closest folder and say so in the commit message. Someone will move it.

## Naming

`Topic_Surname.pdf` for slides, `P1-worksheet.pdf` for worksheets. No spaces in file names, use hyphens. Keep the name the same if you upload a newer version, so links to it do not break.

## How to upload, step by step

1. Sign in to GitHub and open the repository link above.
2. Click into the folder your file belongs in, from the table above.
3. Click **Add file**, then **Upload files**.
4. Drag your file onto the dashed area.
5. In the box at the bottom, write what you added, for example `Add Practical 2 worksheet`.
6. Click **Commit changes**.

That is it. Your file is online straight away.

If you do not have write access to the repository, GitHub shows you a **Propose changes** button instead. Click it and Andy gets a notification to approve. Nothing is lost.

## Formats

- **PDF, please.** It opens on any computer, and participants can read it on a phone during the session. Export from PowerPoint or Keynote: File, Export, PDF.
- If the deck has to stay editable for the next workshop, upload the `.pptx` as well as the PDF, side by side.
- Keep each file under 25 MB, which is the limit the GitHub web uploader accepts.
- Videos do not belong here. Put them on a TSL or GetGenome drive and share the link.

## Permission

Do not upload someone else's talk without asking them first. Check also that what you upload contains no unpublished data belonging to someone else, and no personal information about participants.

## Linking a file from the website

The practical pages on the website have a Materials table with a row for slides and one for worksheets. Once your file is uploaded, tell Andy and he will point the page at it.
