# Data

Input files and pre-computed fallbacks for each practical.

```
practical-01_predict/     Input sequences, plus pre-computed predictions
practical-02_interpret/   Confidence data and annotated example models
practical-03_compare/     Structure set for comparison, plus pre-computed matrix
practical-04_design/      Design targets, plus a pre-computed design set
```

## The rule about fallbacks

Every step that depends on a queue, a download, or conference wifi has a
pre-computed result in the matching folder. A participant who loses ten minutes
to a network problem should lose ten minutes of the workflow, not the session.

Facilitators: test these on a throttled connection before the workshop.
