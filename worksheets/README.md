# Worksheets

Printable exercise sheets and handouts for the four practical sessions, one
folder per session.

```
practical-01_predict/     AlphaFold Server exercises
practical-02_interpret/   ChimeraX exercises
practical-03_compare/     Structure comparison exercises
practical-04_design/      Inverse folding and binder design exercises
```

Name files `P1-exercises.pdf`, `P2-ChimeraX-exercises.pdf` and so on. Keep the
name the same when you upload a newer version, so links to it keep working.

The step-by-step guide for each session lives on the website under
Practicals. These files are the printable companion to those pages, not a
replacement for them.

Step-by-step upload instructions: [CONTRIBUTING.md](../CONTRIBUTING.md)
