# Worksheets

Printable exercise sheets and handouts for the four practical sessions, one folder per session.

```
practical-01_predict/
practical-02_interpret/
practical-03_compare/
practical-04_design/
```

Name files `P1-worksheet.pdf`, `P2-worksheet.pdf` and so on, with no spaces. Keep the name the same when you upload a newer version, so links to it keep working.

Upload instructions: [CONTRIBUTING.md](../CONTRIBUTING.md)
