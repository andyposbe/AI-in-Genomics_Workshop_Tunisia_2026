# practical-03_compare

Input files for the Compare session, one folder per dataset. The worksheet for
this session is
[`worksheets/Day2_Practicals-3-4_Worksheet.pdf`](../../worksheets/Day2_Practicals-3-4_Worksheet.pdf).

Datasets 1 and 2 hold secreted proteins of the rice blast fungus
*Pyricularia oryzae*, named Protein 1 to Protein 4. Dataset 3 is a wider set of
fungal effector structures.

## dataset-1

Sequences, for the searches in Exercise 1.

| File | What it is |
|---|---|
| `Proteins_1-4.fasta` | Protein 1 to Protein 4, in one multi-FASTA |

## dataset-2

Structures, for Exercise 2. Exercise 3 searches Foldseek with
`Protein_4_AVR-Mgk1.pdb` from this folder.

| File | What it is |
|---|---|
| `Protein_1_BAS4.pdb` | Protein 1, BAS4 |
| `Protein_2_IF.pdb` | Protein 2, IF |
| `Protein_3_AVR-PikD.pdb` | Protein 3, AVR-PikD |
| `Protein_4_AVR-Mgk1.pdb` | Protein 4, AVR-Mgk1 |

## dataset-3

80 MAX-fold effector structures as `.pdb`, for the multiple structure alignment
in Exercise 4. They come from Lahfa *et al.* (2024), *The structural landscape
and diversity of* Pyricularia oryzae *MAX effectors revisited*, PLOS Pathogens:
[doi.org/10.1371/journal.ppat.1012176](https://doi.org/10.1371/journal.ppat.1012176).
