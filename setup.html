Before you arrive

Please come to the workshop with the software already installed.

1. Bring a laptop

You will need to bring your own laptop. Computers are not provided at either venue. You need to be able to install software on it, so if your institute's laptop blocks installation, sort that out with your IT team beforehand.

2. Install UCSF ChimeraX

  • Download: https://www.cgl.ucsf.edu/chimerax/download.html
  • Make sure to select the correct version for your computer's operating system (see the list under Other releases).
  • Install it, then open it once to confirm that it launches.

If you run into any issues installing or opening ChimeraX, email andres.posbeyikian@tsl.ac.uk before the workshop. Do not worry if it is still not working on the day, as we can troubleshoot together during the session.

3. Create an AlphaFold Server account

Sign in at https://alphafoldserver.com/ with a Google account. If you do not have one, make one now.

Still stuck?

Email andres.posbeyikian@tsl.ac.uk with your operating system and the error you are seeing. For anything that is not about software, email getgenome@tsl.ac.uk.
