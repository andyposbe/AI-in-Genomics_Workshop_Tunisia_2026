# Slides

Slide decks from the talks and session introductions, added within two weeks of
each workshop.

```
day1/    Introduction to AI for genomics; theoretical introduction to AlphaFold
day2/    Session introductions and the design overview
flash/   Flash talks by local researchers, with the speaker's permission only
```

Name files `Topic_Surname.pdf`, no spaces. PDF please, so they open anywhere.
If a deck needs to stay editable for the next workshop, upload the `.pptx`
alongside the PDF.

Step-by-step upload instructions: [CONTRIBUTING.md](../CONTRIBUTING.md)
