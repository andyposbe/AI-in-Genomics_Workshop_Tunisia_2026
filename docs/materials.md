# Slides and worksheets

Everything from the workshop is collected here, and we keep adding to it as the
sessions run and afterwards.
{: .fs-5 .fw-300 }

## Where each thing lives

| Material | Where to find it |
|---|---|
| Step-by-step guide for each practical | The four [Practicals](practicals/index.md) pages on this site |
| Slide decks from the talks and session introductions | [`slides/`](https://github.com/andyposbe/AI-in-Genomics_Workshop_Tunisia_2026/tree/main/slides) |
| Flash talks by local researchers | [`slides/flash/`](https://github.com/andyposbe/AI-in-Genomics_Workshop_Tunisia_2026/tree/main/slides/flash), with the speaker's permission |
| Printable worksheets and handouts | [`worksheets/`](https://github.com/andyposbe/AI-in-Genomics_Workshop_Tunisia_2026/tree/main/worksheets), one folder per practical |
| Input sequences and pre-computed results | [`data/`](https://github.com/andyposbe/AI-in-Genomics_Workshop_Tunisia_2026/tree/main/data), one folder per practical |
| Tools, ChimeraX commands, reading | [Resources](resources.md) |

The practical pages are the live version of the material. We edit them during
the sessions and correct them afterwards, so refresh the page if you are
following along on a laptop.

Slide decks are added within two weeks of each workshop.

## For trainers and facilitators

To add your own slides or a worksheet, follow
[CONTRIBUTING.md](https://github.com/andyposbe/AI-in-Genomics_Workshop_Tunisia_2026/blob/main/CONTRIBUTING.md)
in the repository. It is written for people who have never used GitHub: sign
in, open the right folder, drag the file in, click commit. Nothing else.

In short:

- Day 1 talks go in `slides/day1/`, Day 2 talks in `slides/day2/`, flash talks in `slides/flash/`.
- Worksheets go in `worksheets/practical-01_predict/` and the matching folders for the other three sessions.
- Name files `Topic_Surname.pdf` for slides and `P1-exercises.pdf` for worksheets, with no spaces.
- Export to PDF. Add the `.pptx` next to it only if the deck needs to stay editable.
- Never upload someone else's flash talk without asking them first.

To fix something on a practical page, open that page and click **Suggest a
change to this page** at the foot of it.
